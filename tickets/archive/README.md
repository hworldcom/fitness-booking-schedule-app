# Work-record archive

This directory contains Completed and Cancelled development tickets and coordination records grouped by their primary area:

- [Frontend](frontend/): completed routes, browser behavior, interface and client-side work.
- [Backend](backend/): completed server, authentication, data, service and delivery planning work.
- [Organisatory](organisatory/): completed contributor workflow, repository/document structure and consolidation work.

Archived records preserve implementation decisions and validation evidence but do not replace the current product contract in `docs/mvp-spec.md` or the contributor policy in `AGENTS.md`.

Use the [root work-record index](../README.md) to find current work and archived history. Create later implementation as a new development ticket under the appropriate `tickets/current/<area>/`; create coordination only when multiple peer development tickets need an explicit shared map. Do not reopen or silently rewrite archived records.
