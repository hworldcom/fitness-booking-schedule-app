## Objective and context

Let the coach define an indicative `Sessions start from …` rate and choose whether it is public. The user's later review simplified the original fixed-price/snapshot plan; this ticket owns the starting amount, disclosure and safe public/owner projections, not booking-price terms.

Use [section 19.3](../../../docs/mvp-spec.md#193-starting-prices-and-public-disclosure), the [M10 milestones](../../../docs/mvp-spec.md#12-delivery-milestones) and [acceptance scenarios](../../../docs/mvp-spec.md#13-acceptance-matrix). ## Scope and non-goals

- In scope: optional owner-entered EUR starting amount, independent public-display setting, versioned save/edit/clear/show/hide, money bounds, owner versus public projection and cache invalidation. Provide tested contracts to the editor/cards/website.
- Out of scope: fixed quotes, price snapshots on requests/bookings/messages, changed-price request gates, multiple services/durations, group-price changes, payment collection, the owner/public layouts and media decisions.

## Expected behavior and edge cases

The owner chooses the amount; MovX neither selects nor derives a minimum price. Public output says `Sessions start from €60` for an actual disclosed rate (example only), with private-session context. An absent amount is unknown and zero is explicit Free/zero. Adopt initially hidden disclosure. Hiding retains the owner value but removes it from public projections, HTML/props, metadata/share output and current caches; visual hiding alone fails the contract. A missing/hidden amount omits the numeric line and can lead to Message coach. Concurrent owner edits use revisions and retain error drafts. Amount/disclosure changes never mutate a booking/request or claim a locked quote. Existing group per-person terms remain separate.

## Assumptions, decisions, and dependencies

### Decisions and deviations

The adopted design above was recorded before source edits. A separate optional table and revision prevents rate and content/banner edits overwriting one another. New SQL wrappers preserve older website signatures rather than forcing an atomic app/database replacement. Public wrappers append only filtered JSON; private columns are never loaded as part of a public website/card query.

EUR cents from 0 through 2,147,483,647 are the supported database range, an implementation bound rather than a user-selected pricing cap. There is no per-service catalogue, computed minimum, checkout, quote lock, new booking field or attendance claim. Canonical saves use integer cents. The later editor may use the exact dot/comma decimal helper without rounding a draft to another value. Its unsaved-draft retention remains DEV0315's responsibility.

This is backend work: no owner control or public rate layout has been added. Existing document/metadata/RSC boundaries must omit hidden amounts now; new layouts and username routes must continue consuming the same projection. Route Handler revalidation follows installed Next.js 16.3.8 documentation: mark Home, Explore and `/coaches/[slug]` for fresh server output on the next visit. No-store APIs avoid persisted price responses; this cannot erase a visitor's earlier copy. DEV0331 must include its future canonical/alias paths in equivalent invalidation when those paths exist.

### Contracts, configuration, and operations

- `GET /api/coach/starting-rate`: `{status:"ready",startingRate:{schemaVersion:1,revision,amountCents:null|integer,currency:"EUR",showPublicly,context:"private-session"}}`. An eligible existing coach without a row gets revision 0, null and false; no backfill or new required profile field.
- `PUT /api/coach/starting-rate`: exactly `{schemaVersion:1,expectedRevision,amountCents:null|integer,currency:"EUR",showPublicly:boolean}`, at most 2 KiB, JSON and same origin. Unknown/caller-owned actor fields, invalid numbers/currency or revision fail with 400. Success is `saved`; stale races are 409; signed-out/forbidden/unavailable map to 401/403/503. Errors contain no raw database details or draft amount. Compare-and-swap and SQL mutations roll back before error translation.
- Public `GET /api/coaches/[slug]/starting-rate`: eligible coach returns `{status:"ready",schemaVersion:1}` with optional `startingRate`. The same optional schema-1 DTO on website/card output has only `amountCents`, `currency:"EUR"`, `context:"private-session"`, `label` and `schemaVersion`. Zero is `Sessions start from €0 (Free)`; 6050 cents is `Sessions start from €60.50`. Hidden/unknown coaches use the same 404; hidden/unknown amounts on an eligible coach omit the field. No disclosure flag or owner revision is public.
- APIs return `Cache-Control: private, no-store` and `Vary: Cookie`. New optional DTO fields are additive. Existing SQL functions remain unchanged; deploy migration `20261018000300_coach_starting_rates.sql` after the delivered content/banner migrations, before running this app build. No dependency, environment variable, Auth/Storage setting or hosted rollout is introduced.
- Applied only `20261018000300` and its ledger entry to the repository-verified local Docker database, in one checked transaction, using `node /tmp/dev0313-review/apply-local.mjs`. Precondition: `20261018000200` present and no pricing table/ledger entry. The reviewed migration text was stored in the ledger; later peer `20261018000400` was not applied by this work. No reset or hosted migration.
- Rollback: first run the previous compatible app, which still uses the retained original website functions. Preserve/export private rate rows before any deliberate removal. A separately reviewed forward rollback can then remove the new wrappers/helpers and optional table; do not rewind migration history or reset retained data. Other session/content/media tables need no rollback.
- Rehearsals permit only the named repository local Docker project and loopback application. Isolated databases copy infrastructure schema only, with synthetic seed/media references; no retained user rows/tokens. Real API proof uses three new ticket-tagged accounts and invocation-specific UUID manifests under ignored `tmp/dev0313-starting-rates/`. Cleanup never selects unrelated accounts or unfinished peer fixtures.
