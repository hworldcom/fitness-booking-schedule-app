# Current work records

Current development tickets and coordination records are grouped by their primary area:

- [Frontend](frontend/): Next.js routes, browser behavior, presentation, accessibility, and client-side interaction.
- [Backend](backend/): Next.js server code, authentication, PostgreSQL/Supabase, application services, jobs, and repository infrastructure.
- [Organisatory](organisatory/): contributor workflow, repository/document structure, and cross-cutting consolidation.

Draft, Ready, In progress, and Blocked records live in exactly one category. Use the [root work-record guide](../README.md) for status, relationship and DEV-to-COR conversion rules, the [development-ticket template](../TEMPLATE.md) and the [coordination template](../COORDINATION_TEMPLATE.md). Every DEV record declares one direct COR membership or explicitly states that it is independent. Cross-cutting development tickets use the category that owns their main implementation; coordination records use the category that owns their coordination concern.

After a record is complete or cancelled, finish its evidence and validation before moving it to the matching area in the [archive](../archive/).
